# Starter Project Mahasiswa

Folder ini adalah titik awal praktikum. Ia **sengaja belum lengkap**. Mahasiswa tidak diberi seluruh solusi reference pada awal proyek.

Urutan kerja utama:

1. P1: analisis kebutuhan dan arsitektur.
2. P2: lengkapi `POST /api/v1/predict` dan kontrak request/response.
3. P3: latih, simpan, muat, dan evaluasi model.
4. P4: lengkapi Streamlit agar memanggil FastAPI.
5. P5: lengkapi Dockerfile dan jalankan container.
6. P6–P10: deployment, monitoring, testing, dan UI/UX.
7. P11–P12: progress report dan ekstensi Android Flutter.
8. P13–P16: stress test, dokumentasi, demo end-to-end, dan penyerahan.

Gunakan `exercises/WEEKLY_CHECKPOINTS.md` sebagai checklist. Folder `../reference/` ditujukan untuk dosen/kunci pembelajaran, bukan untuk langsung disalin mahasiswa.
